# Tesla Stock Price Analysis & Forecasting

A Time Series Analysis project exploring Tesla stock price data through trend analysis, seasonality, volatility, moving averages, returns, and time-series forecasting using Prophet.

## 📌 Overview

This project analyzes historical Tesla stock market data and applies different Time Series Analysis techniques to understand how the stock price changes over time.

The analysis focuses mainly on the **Closing Price** and **Trading Volume** and explores patterns such as:

- Long-term trends
- Seasonality
- Stock returns
- Volatility
- Moving averages
- Time-series forecasting

The project also demonstrates how historical stock data can be prepared for forecasting with the **Prophet** model.

## 🎯 Objectives

- Analyze historical Tesla stock price data.
- Understand the trend in Tesla's closing price.
- Examine trading volume over time.
- Analyze seasonal patterns.
- Calculate stock returns and volatility.
- Use moving averages to identify short-term and long-term trends.
- Apply Prophet for time-series forecasting.
- Visualize the forecasting results.

---

## 📊 Dataset

The project uses a historical Tesla stock dataset containing **1,692 records**.

### Main Features

| Column | Description |
|---|---|
| `Date` | Date of the stock record |
| `Open` | Opening stock price |
| `High` | Highest price during the day |
| `Low` | Lowest price during the day |
| `Close` | Closing stock price |
| `Volume` | Number of shares traded |
| `Adj Close` | Adjusted closing price |

The dataset contains no missing values. :contentReference[oaicite:0]{index=0}
