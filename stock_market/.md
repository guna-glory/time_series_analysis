# Tesla Stock Price Analysis & Forecasting

A Time Series Analysis project exploring Tesla stock price data through trend analysis, seasonality, volatility, moving averages, returns, and time-series forecasting using Prophet.

## 📌 Overview

This project analyzes historical Tesla stock market data and applies different Time Series Analysis techniques to understand how the stock price changes over time.

The analysis focuses mainly on the **Closing Price** and **Trading Volume** and explores patterns such as:

- Long-term trends
- Seasonality
- Stock returns
- Volatility
- Moving averages
- Time-series forecasting

The project also demonstrates how historical stock data can be prepared for forecasting with the **Prophet** model.

## 🎯 Objectives

- Analyze historical Tesla stock price data.
- Understand the trend in Tesla's closing price.
- Examine trading volume over time.
- Analyze seasonal patterns.
- Calculate stock returns and volatility.
- Use moving averages to identify short-term and long-term trends.
- Apply Prophet for time-series forecasting.
- Visualize the forecasting results.

📈 Trend Analysis

The Tesla closing price is plotted over time to observe its long-term movement.

The analysis identifies a general upward movement in the closing price over the period covered by the dataset, along with periods of decline and fluctuations.

Trading volume is also visualized to observe changes in the number of shares traded over time.

🔄 Seasonality Analysis

Seasonal decomposition is performed using a multiplicative decomposition model with a period of 30.

seasonal_decompose(
    df['Close'],
    model='multiplicative',
    period=30
)

The decomposition separates the series into:

Trend
Seasonal component
Residuals

The analysis suggests a general upward trend, some recurring fluctuations, and increasing residual variation over time.

📉 Volatility Analysis

Daily stock returns are calculated using percentage change:

df['Return'] = df['Close'].pct_change()

A rolling volatility measure is then calculated using a 252-day window:

df['Volatility'] = (
    df['Return'].rolling(window=252).std()
    * np.sqrt(252)
)

The analysis shows several periods of increased volatility, indicating periods where Tesla's returns experienced larger fluctuations.

📊 Moving Average Analysis

Two moving averages are explored:

10-Day Moving Average (MA10) — short-term trend
50-Day Moving Average (MA50) — longer-term trend

Moving averages are used to smooth short-term price fluctuations and make broader trend movements easier to observe.

The project also discusses the concept of:

Bullish crossover
Bearish crossover
📈 Returns Analysis

Daily returns are calculated from the closing price.

A positive return represents an increase in the closing price, while a negative return represents a decrease.

This provides another perspective on the daily movement and variability of the stock.

🤖 Prophet Forecasting

The Tesla closing-price data is converted into the format required by Prophet:

ds → Date
y  → Close

The resulting dataset contains:

ds          y
2010-06-29  23.89
2010-06-30  23.83
2010-07-01  21.96
...

A Prophet model is then initialized:

model = Prophet()

The notebook attempts to generate a 365-day future forecast and visualize the predicted values and forecast components.
